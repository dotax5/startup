# AI Chat

Легковесное одностраничное приложение для общения с AI-моделями через OpenRouter API.

## Возможности

- Управление несколькими чатами (создание, переключение, удаление)
- Поддержка различных AI-моделей через OpenRouter (GPT, Nemotron, GLM)
- Переключение тёмной и светлой темы
- Действия с сообщениями: копирование, удаление, регенерация ответа
- Рендеринг Markdown (заголовки, жирный текст, курсив, код, списки, таблицы, цитаты, ссылки)
- Отображение времени генерации ответа
- Автосохранение в localStorage браузера
- Автоизменение размера textarea, отправка по Enter

## Запуск

1. Клонируйте репозиторий
2. Откройте `index.html` в любом современном браузере
3. Выберите AI-модель в боковой панели
4. Начните диалог
